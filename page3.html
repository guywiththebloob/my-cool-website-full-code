Aqui podras ver los programas que fueron usados para hacer este sitio Web! Al mismo tiempo que las tecnicas usadas para cada cosa.

HTML Es el codigo base de todo este ejercicio, es literalmente una de las formas mas simples para lograr hacer un sitio Web, entonces tiene bastannte sentido que fue escrito con este tipo de codigo

CSS Fue tambien de gran ayuda cuando se trato de codigos mas complicados pero que tuvieran un poco mas de hueso, honestamente creeria que podria describir CSS como el JavaScript de HTML, ya que es muy facil de aplicar en codigo.

Programacion Orientada a Objetos O tambien conocido como POO fue una de las razones principales de por que la pagina de Guardar Informacion siquiera puede existir, ademas de tambien ser uno de los puntos claves de todo este proceso.

La Inteligencia Artificial O IA, por mas que no me guste aceptarlo, fue de gran ayuda cuando se trato de codigos los cuales no tenia completamente dominado. Una gran mayoria del Codigo de Guardar Informacion Y fue por ayuda de ello, lo cual no me gusta realmente admitir, pero tampoco le voy a quitar el credito. Es una herramienta que me ayudo.

Originnalmente este sitio web entero hiba a estar escrito en NetBeans pero uno de los problemas mas grandes que paso con eso fue que los servidores eran realmente dificles que hacer en general, entonces el programa fue cambiado a Visual Studio Code el cual honestamente es bastante bueno ya que lo logre pobrar.

Para mi ultima carta de amor, tengo que ser honesto y darle demasiado credito a W3Schools, ya que ellos fueron una de las razones principales para que pudiera encontrar mayoria de codigos bastante utiles y divertidos de usar en todo este proyecto.
